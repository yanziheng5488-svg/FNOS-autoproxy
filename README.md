# AutoProxy · 飞牛 fnOS 自动代理转码应用

> **已上架飞牛官方应用商店**：在 fnOS「应用中心」搜索「**达芬奇自动代理**」即可直接下载安装，无需任何命令行操作。

一个跑在 **飞牛 fnOS（原生应用，无需 Docker）** 上的后台服务：监控指定目录，一旦有新增视频文件，自动调用 ffmpeg 转码为低清代理，供 **DaVinci Resolve（达芬奇）** 剪辑使用。

- 纯 Python 3 标准库实现，无第三方依赖，`platform="all"` 兼容 x86 / ARM。
- 转码时保留 **文件名 + 时间码**，代理输出到监控目录下的 `Proxy` 子文件夹（与 Blackmagic Proxy Generator 目录约定一致），达芬奇可顺利重链。
- 内置轻量 Web 管理界面：查看配置、任务队列、日志，支持立即扫描 / 重试 / 清理。

---

## 1. 工作原理

```
监控目录 /vol1/1000/素材/
├── clipA.mov
└── day1/
    └── clipB.mxf
        │  (检测到新增文件，等待写入完成)
        ▼
ffmpeg 转码（保留文件名 + 时间码）
        ▼
监控目录 /vol1/1000/素材/Proxy/
├── clipA.mov       ← DNxHR LB 低清代理
└── day1/
    └── clipB.mov
```

代理文件与源文件同名（仅扩展名可能不同），且时间码一致，达芬奇据此自动关联。

## 2. 前置依赖（无需命令行）

**正常情况下你什么都不用装。** fnOS 系统自带 `ffmpeg`（位于 `/usr/bin/ffmpeg`，已编译 VA-API 硬件转码），`python3` 也已内置。

应用启动时会自动检测 ffmpeg，按优先级查找：

1. 应用内置 `app/bin/ffmpeg`
2. fnOS 自带的 `/usr/bin/ffmpeg`
3. 系统 `PATH` 中的 ffmpeg

**万一检测不到**（极少数精简设备），应用提供两种零命令行的兜底：

- **安装/设置时自动补齐**：安装向导里有「缺少 ffmpeg 时自动安装」开关（默认开启）。开启后，应用在安装时、或你在「应用设置」里重新保存一次配置时，会自动尝试补齐 ffmpeg（需联网，失败也不影响安装）。
- **手动内置**（可选）：在打包前把静态 ffmpeg 可执行文件放入 `app/bin/`（命名 `ffmpeg`、`ffprobe`），应用会优先使用。若内置了架构相关的二进制，请把 `manifest` 的 `platform` 从 `all` 改为 `x86` 或 `arm`。

## 3. 打包（.fpk）

1. 下载打包工具 [fnpack](https://developer.fnnas.com/docs/cli/fnpack/)（Windows/Linux/macOS 均有）。
2. 在本项目目录执行：

```bash
fnpack build
```

会生成可安装的 `AutoProxy-1.2.0.fpk`（具体文件名以工具输出为准）。

---

## 4. 安装与配置

1. 打开飞牛 fnOS 的「**应用中心**」，搜索「**达芬奇自动代理**」，点击下载安装即可（应用已上架飞牛官方应用商店，全程图形界面，无需命令行）。
2. 安装向导中只需填写：
   - **代理编码格式**：推荐 `DNxHR LB`（Windows + 达芬奇最流畅）。
   - **代理分辨率**：推荐 `1080p`。
   - **GPU 硬件加速**：默认「自动」即可。
3. **用飞牛文件管理器选目录（关键）**：到「应用中心 → 自动代理 → 应用设置 → 授权目录」，点击「+ 文件夹」，用飞牛自带的文件管理器选择素材文件夹（可加多个，设读写权限）。
4. **重启应用**使授权目录生效（新增授权目录后需重启一次应用才会读取）。
5. 打开应用（经飞牛统一网关 `/app/autoproxy`，**无需任何端口**），进入 Web 界面确认「运行正常」，授权目录会自动显示在监控列表里。

---

## 5. 达芬奇（DaVinci Resolve）工作流

以 DNxHR LB 代理为例：

1. 素材导入后，达芬奇会自动在素材目录下发现 `Proxy` 子文件夹中的同名代理。
2. 剪辑时启用代理模式：
   - 菜单 **Playback（回放）→ Proxy Handling / 使用代理**，或在时间线播放控制区切换代理优先。
3. 剪辑全程用低清代理保证流畅；最终输出时，达芬奇按文件名 + 时间码自动回链到原始高清素材渲染成片。

> 若达芬奇未能自动关联，可手动：媒体池右键素材 → **Relink Proxy Media（重链代理）**，指向 `Proxy` 目录。

## 6. 配置说明

配置保存在应用配置目录的 `config.json`。编码/分辨率/硬件加速通过应用设置（向导）修改，修改后服务自动重启。

| 字段 | 含义 | 可选值 |
|------|------|--------|
| `watch_dirs` | 手动监控目录列表（支持多个） | 数组，如 `["/vol1/a", "/vol2/b"]` |
| `codec` | 代理编码 | `dnxhr_lb` / `h264` / `h265` / `prores_proxy` |
| `resolution` | 代理分辨率 | `1080p` / `720p` / `half` / `original` |
| `hwaccel` | GPU 硬件加速 | `auto`（可用则用）/ `off` |
| `port` | Web 端口（仅 TCP 回环 fallback 模式使用） | 默认 `9080`；主模式不监听端口 |

高级参数（`config.json` 内可选）：`scan_interval`（扫描间隔秒，默认 5）、`stable_wait`（文件写入稳定等待秒，默认 10）、`workers`（并行转码数，默认 1）。

### 安全模型
- **接入飞牛统一网关（默认）**：应用只监听 Unix Socket（`autoproxy.sock`），**不监听任何 TCP 端口、不暴露公网端口**；访问走飞牛统一网关 `/app/autoproxy`，鉴权由飞牛登录态完成，未登录请求会被网关拦截（返回 invalid token），不会透传到应用。
- **可选 TCP 回环 fallback**：如需直接监听端口，仅监听 `127.0.0.1`（回环、不监听公网），且必须用 `--auth-token` 设置鉴权 token，否则所有请求返回 401。
- **路径安全校验**：手动添加监控目录时校验绝对路径，拒绝 `..` 穿越、根目录与系统目录；静态文件服务带目录穿越防护。

### 监控目录（两种来源）
- **授权目录（推荐）**：在「应用中心 → 应用设置 → 授权目录」用**飞牛自带的文件管理器**选择。应用启动时经 `TRIM_DATA_ACCESSIBLE_PATHS` 环境变量自动读取，无需手填路径，权限由飞牛统一管理。新增授权目录后需重启应用生效。
- **手动目录**：打开应用 Web 界面，在「监控目录」区手动输入绝对路径增删（作为补充，用于授权目录未覆盖的场景）。即时生效并持久化。
- 两类目录会去重合并监控；每个目录独立生成各自的 `Proxy` 子文件夹，互不影响。

### GPU 硬件加速
- 应用启动时自动检测 **Intel VAAPI**（`/dev/dri/renderD128`）与 **NVIDIA NVENC**。
- **H.264 / H.265** 支持 GPU 硬件编码，可大幅降低 CPU 占用。
- **DNxHR LB / ProRes Proxy 没有 GPU 硬件编码器**（专业中间格式，只能 CPU 编码），达芬奇推荐格式若选 DNxHR 将始终用 CPU——这是格式本身的限制，不是缺陷。
- 应用已申请 `video`/`render` 用户组权限以访问 GPU 设备。
- 界面「转码设置 → GPU 加速」会如实显示当前状态（硬件加速中 / 该编码仅 CPU / 未检测到 GPU / 已关闭）。

### 值守（防闪退）
- 应用启动时会带一个**值守循环**：主程序一旦闪退，会在 3 秒后自动重启，日志中记录 `[watchdog]` 字样。
- 正常「停止」应用时值守会一并退出，不会误重启。

## 8. 故障排查

| 现象 | 处理 |
|------|------|
| Web 界面提示「未检测到 ffmpeg」 | fnOS 通常已内置 `/usr/bin/ffmpeg`；若仍未检测到，到「应用设置」重新保存一次配置（勾选「自动安装」），应用会自动补齐，无需命令行 |
| 提示「监控目录不可访问」 | 到应用设置 → 授权目录 中授权该目录（可读写） |
| 文件不转码 | 确认文件扩展名在支持列表内（.mp4/.mov/.mxf/.braw 等），且文件已完全写入；查看 Web 界面日志 |
| DNxHR 编码失败 | 某些 RAW 格式（如 R3D）需特殊 ffmpeg 编译；可改用 `h264` 代理，或确认源文件可被 ffmpeg 解码 |

支持扩展名：`.mp4 .mov .mxf .mts .m2ts .m2t .avi .mkv .mpg .mpeg .ts .wmv .flv .webm .m4v .3gp .braw .r3d .ari .dng`
